# Momo 纯静态图库管理器

使用新版桌面 Chrome 或 Edge 打开根目录“管理图库.html”，点击“选择本地图库目录”，选中下载或克隆的图库文件夹并授予读写权限。无需 Node.js、npm、服务或安装程序。也可通过 HTTPS 打开 manager/index.html，再选择本地目录；普通不安全 HTTP 和不支持文件夹写入的浏览器会显示明确说明。每次打开或刷新页面需重新选择目录。

只读写你选择的本地图库文件夹，不调用 Git、不上传 CDN、不保存远程凭据。页面即使放在线上，修改的也是访问者自己授权的本地文件，不是服务器资源。修改后请自行提交/推送或上传。

支持正式单资源/合集 ZIP 导入预览、编辑目录名称/分类/标签/说明、批量移出目录、目录恢复。目录元信息不修改 ZIP、ID、版本或校验。移出目录保留旧 ZIP 和缩略图，兼容已有链接。每次目录修改前在当前浏览器 IndexedDB 保存最多50份快照（按图库ID、页面来源区分），不会写进图库仓库；清理浏览器数据或换浏览器后无法恢复。重要备份请在“目录恢复”下载 JSON，并可从 JSON 恢复（要求图库身份和引用包校验通过）。

不自动渲染缺失缩略图，也不编辑公式/图片内容。不要让其他程序同时修改目录；同来源窗口的写入通过浏览器锁串行，旧目录修订会被拒绝。单文件通过浏览器写入流提交，但不能保证整个文件夹或其他程序参与的原子事务。Chrome文件夹权限、安全上下文和文件系统限制由浏览器管理，请勿通过禁用安全保护来运行。

管理器由 MomoTextureForge/build-library-manager.mjs 生成。开发者构建需要 Node 与开发依赖，最终使用者不需要。
