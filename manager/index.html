MOMO LIBRARY MANAGER

本地图库管理器

只修改本机文件

打开本地图库

无需安装 Node.js 或启动服务。首次使用时选择图库文件夹并授权；以后会记住目录，权限有效时自动打开，需要授权时点击“继续使用”。

浏览器不允许网页自动取得所在文件夹的读写权限。即使通过线上页面打开，也只修改你授权的本地文件夹，不上传资源、不操作 Git。

修改保存在本地。完成后，请自行提交并推送 Git，或上传到 CDN。现有订阅地址和图库 ID 保持不变。

“移出目录”保留旧文件；“彻底删除”同时删除当前引用的 ZIP 和缩略图（共用文件保留），无法通过目录快照找回。每次目录修改前会在当前浏览器保存恢复快照，不写入图库仓库；清理浏览器数据会丢失快照，重要目录请通过“目录恢复”下载 JSON 备份。

编辑目录信息

只修改 index.json 中的展示信息，资源 ZIP、ID、版本和校验值不变。

确认导入

    相同 ID、相同版本的不同内容会被拒绝；已有文件不会被覆盖。重复资源保留当前目录信息。

    恢复目录快照

    恢复只修改目录，不删除资源文件，也不能找回已彻底删除的文件。快照保存在当前浏览器，最多50份，不随仓库携带。换浏览器或清理网站数据后不可用；可下载 JSON 备份留存。
